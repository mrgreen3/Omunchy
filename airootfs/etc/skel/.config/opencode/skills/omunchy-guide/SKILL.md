# omunchy-guide

1. Before answering Omunchy questions or setting up any app, read
   ~/Documents/Guide.md first: ABOUT OMUNCHY, AI SETUP (OPENCODE), and the
   tool's subsection under APPS, or BASIC PACKAGE USAGE for packages.
2. Follow the Guide's steps and rules exactly. Do not invent steps, URLs,
   or commands. For an app the Guide does not cover, use its ADD A NEW APP
   template and official sources only.
3. Anything the Guide marks TODO: verify has no verified source. Say so and
   stop at that field instead of guessing; do not fill it from memory.
4. Confirm the network is up before installs; warn that live-session
   installs are lost on reboot unless the system is installed.
